Decision register

Fifteen sections from the original decision log (ANALYZE_PAGE_REDESIGN_DECISIONS.md §2) plus one added Day 111, each mapped to the canon principle that actually governs it.

Technical Read
01 Trend Template / RSI / RS Rating
Engine Locked ① Trend · ② Momentum

Backtest-validated, parity-tested across 86,400 combos. No reliability problem — the opposite of Fundamentals' situation.

02 ADX — trend-confirmation modifier
Engine Locked ① Trend

Appends "trend not yet confirmed" instead of silently vanishing — the classic "flat/tangled average is a no-trade signal" caution, made visible.

03 ADX — position-size trigger
Info Locked ⑤ Sizing

The card carried three mutually contradicting ADX→size mappings at once. Reduced to a raw number — no recommendation to be wrong about.

Market Regime
04 Market Regime (VIX + SPY vs. 200-SMA)
Info Locked · Revised Day 110 ① Trend · ⑦ Volatility

Was a hard gate (Day 109); reversed under direct pushback (Day 110). Even Moreira & Muir's own mechanism scales exposure — it doesn't block a trade outright. Update (Day 111): the decision doc's own copy (§6) is now fixed to the post-reversal wording. Update (Day 112): the published mockup file — the last piece out of sync — has been synced to match.

Fundamentals & Sentiment
05 Fundamentals (ROE / Rev. Growth / D-E)
Info Locked outside the canon

Value/fundamental analysis (Graham-Buffett) is a separate tradition from these nine technical principles. Becomes a binary red-flag screen — a 40% live/backtest data mismatch made the scored version fragile, not the idea of fundamentals itself.

06 Sentiment (Fear & Greed)
Info Locked, unchanged ⑧ Sentiment

Already the reference implementation this whole redesign extends — informational since Day 70. Only a silent-fallback display fix is queued.

Risk, Reward & Execution
07 Risk:Reward
Info Locked ⑤ Sizing · ⑥ Stops

R:R is a downstream computation of two Match-verdict principles — the math is sound in theory. The problem is implementation: 4 different formulas exist in-app, 2 on the same card. Shown plain, no color ramp, no gate. Update (Day 111): the root cause is now precisely identified — see item 08's note below.

08 Entry / Stop / Target computation
Engine Locked ⑥ Stops

ATR-based stops — the Turtles' N-multiple mechanic, unchanged. Computing the level stays automated; judging if the resulting R:R is good enough moves to the human (item 07). Update (Day 111, Golden Rule 53): the S&R engine's "nearest support" selection was found to actually select the most extreme level in range, not the nearest one — graded 2/10 against industry proximity-weighted standards. Every R:R and stop on this page is downstream of it. Update (Day 112) — FIXED and shipped: _pivot_sr() now genuinely selects the nearest levels per side, verified live (e.g. META's nearest resistance moved from a phantom ~22%-away level to a real one 0.3% above price). A paired backtest also showed the old momentum profit-factor number was partly propped up by this same bug — corrected honestly, logged, not tuned back (Golden Rule 56). This was "just arithmetic" only in the sense that it's now correct arithmetic.

Position Sizing
09 Position size label (FULL / HALF / REDUCED)
Info Locked ⑤ Sizing

One of three sources was hardcoded "half" — zero computation behind it, live since Day 39. Deleted; replaced by raw sizing inputs plus an unconditional calculator CTA.

10 VIX position-size multiplier
Engine in calculator Info on card Locked ⑦ Volatility

The literal VIX-banded sizing variant the research names. Stays mechanical only inside the tool a human deliberately opens — not on the page shown unprompted.

Descriptive Cards
11 MTF Confluence · S&R · Price Structure · Pattern · Breakout
Info Locked, unchanged ① Trend · ④ Volume

Already the target pattern — descriptive, never suppresses anything. Update (Day 111): a full technical audit graded all five — Price Structure and Breakout Status both scored 9/10 (genuinely well-built); MTF Confluence 3/10 (concept sound, confidence score arbitrary); Pattern Detection's recognition logic 8/10 but its price target only 1.5/10 (a flat percentage, never checked against real resistance). Update (Day 118) — both weak spots FIXED: MTF Confluence now has a graduated score in place of the arbitrary one, and Pattern Detection's target uses the measured move (Day 112) or, for a VCP, the nearest real resistance (Day 118). The card's R:R caveat is closed.

Added Day 111 — outside the original process
15 Mean-Reversion Read
Engine New · Locked Day 111 ③ Mean Reversion

Never part of the original 13-item Q&A process — MR's own signal card has existed on the Analyze page since Day 70, but this whole redesign conversation never once addressed it. Added to the mockup Day 111, tagged Engine rather than Info: unlike Fundamentals or R:R, this signal was confirmed against its own pre-registered bar (Day 111) and stress-tested for cluster inflation (held at PF 2.24 with the worst 3-day cluster removed) — the only track in the project's history to genuinely clear that bar. Update (Day 113): the whole paper-trading/forward-testing program was discontinued at the user's own direction ("I want to use Claude and STA as analysis engine and recommendation, I will take care of stuff myself") — MR closes it out as its final result: 241 closed trades, 70.5% win rate, profit factor 2.00 (all positions now closed; the 2.46 shown here in September was before the last trades closed). No further trades will accumulate. Doesn't gate Technical Read; Technical Read doesn't gate it — two independent, parallel reads. The scanner behind it (/api/mr/scan) is live-wired to the Scan tab.

Also new since this was first published (Day 111): the legacy fundamentals scorer (scoringEngine.js) was found to still compute a second, differently-thresholded fundamentals score — including a Forward P/E component this redesign never discussed — every single analysis run. It's dead code today (nothing renders it), but a landmine if ever reconnected without this context. Logged in ANALYZE_PAGE_REDESIGN_DECISIONS.md §9, not yet deleted.
